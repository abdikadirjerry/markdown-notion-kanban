# Notion-Style Markdown Kanban (`ts-markdown-notion-kanban`)

A minimalist Notion-inspired project workspace featuring Kanban columns, markdown task notes, priority tags, and clean editorial design built with React, TypeScript, and Tailwind CSS.

## Features

- **Editorial Kanban Layout:** Backlog, In Progress, and Completed workflow columns.
- **Task Note Creation:** Modal dialog for adding new tasks with priority and tag classifications.
- **Interactive State Transitions:** Seamless column movement for task tracking.
- **Strict TypeScript Types:** Complete interface definitions for tasks and columns.

## Setup & Running

1. Clone repository & install dependencies:
   ```bash
   cd ts-markdown-notion-kanban
   npm install
   ```
